# Beautiful UI adaptations

Recommendation Card, Context Cards and Task Rows are adapted from
https://github.com/slev12397/beautiful-ui/tree/main/components/primitives
(retrieved 2026-09-07), by Shane Levine, https://www.beautifului.dev/.

Surface replaces the original gallery atoms with shadcn controls and theme tokens.
Sample data, simulated task sequences, confidence meters, acceptance simulation,
and entrance animations are removed. Components display persisted assessment evidence
and work states only. The upstream MIT license is retained in LICENSE.md.
