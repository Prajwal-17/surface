# Surface

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users and purpose

Surface is a personal research and job-review workspace. Its user scans collected jobs, checks fit against a personal profile, reads original evidence, researches companies, and saves or dismisses opportunities.

## Capabilities and constraints

Keep Jobs, Companies, Activity, Schema, Settings, Profile, onboarding, and email authentication. Companies owns discovery, watchlists, decisions, and research; company readers have Overview and Research tabs, with an expanded company view for longer reading. Preserve existing reports, sources, Q&A, notes, company IDs, and old Research links. Report generation remains explicit through Run research; Refresh details checks public information. Preserve source management, saved searches, résumé review, streaming research, citations, clarification, validation, and explicit job assessments. Eligibility, assessment freshness, availability, and review status are distinct facts. Missing or stale assessments never imply a zero fit score.

Use the existing React, Vite, Tailwind, Radix, and React Query architecture. Route paths, URL filters, pagination, theme preference, API contracts, database, and backend behavior remain compatible. The revamp adds only local versioned layout preferences and scoped keyboard navigation.

## Accessibility

Meet WCAG AA text contrast; provide visible focus, labeled statuses, accessible resizing, keyboard navigation, reduced motion, and 44px touch targets. Reading text remains comfortable at mobile sizes and browser zoom.

## Brand commitment

The October 2026 brief specifies T3 Code's default neutral dark chrome and blue actions as the reference, adapted with local Geist typography and an original geometric Surface mark.
